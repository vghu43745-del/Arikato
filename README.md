# បណ្ណាល័យ សុវណ្ណ - Sovann Library Website

វេបសាយរៀនភាសាជប៉ុន សម្រាប់អ្នកនិយាយភាសាខ្មែរ។

## របៀបដាក់លើអ៊ីនធឺណិត (ឥតគិតថ្លៃ)

### វិធីងាយបំផុត៖ Netlify Drop
1. ចូលទៅ https://app.netlify.com/drop
2. អូសโฟល់ឌ័រ `sovann-website` ទាំងមូលចូល
3. រង់ចាំ ១០-២០ វិនាទី → បាន Link រួចរាល់

### វិធីទី២៖ GitHub Pages
1. បង្កើត Repository ថ្មីនៅ GitHub
2. Upload ឯកសារទាំងអស់ក្នុងโฟល់ឌ័រនេះ
3. Settings → Pages → Deploy from branch `main`

### វិធីទី៣៖ Vercel
1. ចូល https://vercel.com
2. Import project ឬ drag & drop โฟល់ឌ័រ

## រចនាសម្ព័ន្ធឯកសារ
- `index.html` → ទំព័រដើម
- `dictionary.html` → ទំព័រវិចនានុក្រម

## បន្ថែមពាក្យបន្ថែម
បើចង់បន្ថែមពាក្យពីឯកសារ Word ចូលទៅក្នុងវិចនានុក្រម សូមប្រាប់ខ្ញុំ។
